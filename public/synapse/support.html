Synapse Notes support

Synapse Notes for iPhone and iPad, by Everald Tah.

To report a bug, ask a question or request a feature, open an issue on GitHub: github.com/Everaldtah/synapse/issues. Say which version you use (Settings > About) and which iPhone or iPad model. A screenshot helps.

Synapse is free software under the GPL-3.0. The source code is at github.com/Everaldtah/synapse.

Choosing an AI model

Open Settings > AI models. You can use:

  • Apple Intelligence on the device (iPhone 15 Pro or newer, or an iPad with M1 or newer, with Apple Intelligence turned on).
  • An open model you download in the same screen. It runs on the device and needs no account.
  • A cloud model. Add a free provider under Settings > API providers (some need no key), paste an Anthropic API key, or pair Synapse Bridge (below). Synapse asks before it sends anything to a cloud service for the first time.

The editor, databases, links, graph, search, recording and import/export all work without any AI model.

Synapse Bridge

Synapse Bridge is an optional program for your Mac or PC. It lets Synapse use the Claude Code or Codex command-line tools that you have signed in to with your own Claude or ChatGPT account, and run commands in a sandbox on that computer. The app works fully without it.

  1. Install Node.js 20 or newer.
  2. Install Claude Code and run claude auth login, or install Codex (npm i -g @openai/codex) and run codex login.
  3. Get the bridge and start it: 
    git clone https://github.com/Everaldtah/synapse
cd synapse/bridge
npm install
node synapse-bridge.mjs
  4. In Synapse, open Settings > Cloud connection and tap Scan pairing QR code.

The iPhone and the computer must be on the same network, or both on a private network such as Tailscale.

Your files

  • Your workspace is stored on the device, in the Files app under On My iPhone / On My iPad > Synapse.
  • Export everything as a Markdown vault under Settings > Export Markdown vault, and import Markdown folders under Settings > Import Markdown / Obsidian vault.

Privacy

Synapse has no accounts, analytics or ads. Read the privacy policy.
